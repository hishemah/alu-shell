# Shell, init files, variables and expansions

Two-line Bash scripts about aliases, local and global variables, arithmetic expansion and base conversions.

| File | Description |
| ---- | ----------- |
| `0-alias` | Creates an alias `ls` with value `rm *` |
| `1-hello_you` | Prints `hello` followed by the current Linux user |
| `2-path` | Adds `/action` as the last directory of the `PATH` |
| `3-paths` | Counts the number of directories in the `PATH` |
| `4-global_variables` | Lists environment variables |
| `5-local_variables` | Lists all local variables, environment variables and functions |
| `6-create_local_variable` | Creates a local variable `BEST` with value `School` |
| `7-create_global_variable` | Creates a global variable `BEST` with value `School` |
| `8-true_knowledge` | Prints 128 plus the value of `TRUEKNOWLEDGE` |
| `9-divide_and_rule` | Prints `POWER` divided by `DIVIDE` |
| `10-love_exponent_breath` | Prints `BREATH` to the power `LOVE` |
| `11-binary_to_decimal` | Converts `BINARY` from base 2 to base 10 |
| `12-combinations` | Prints all two-letter lowercase combinations except `oo` |
| `13-print_float` | Prints `NUM` with two decimal places |
| `14-decimal_to_hexadecimal` | Converts `DECIMAL` from base 10 to base 16 |
| `15-rot13` | Encodes and decodes text with rot13 |
| `16-odd` | Prints every other line of the input, starting with the first |
| `17-water_and_stir` | Adds `WATER` (base water) and `STIR` (base stir.) and prints the result in base bestchol |
