# Shell, basics

Two-line Bash scripts covering navigation, listing, file manipulation and links.

| File | Description |
| ---- | ----------- |
| `0-current_working_directory` | Prints the absolute path of the current working directory |
| `1-listit` | Lists the contents of the current directory |
| `2-bring_me_home` | Changes the working directory to the user's home directory |
| `3-listfiles` | Lists the current directory in long format |
| `4-listmorefiles` | Lists the current directory in long format, including hidden files |
| `5-listfilesdigitonly` | Same as above, with numeric user and group IDs |
| `6-firstdirectory` | Creates the directory `/tmp/my_first_directory` |
| `7-movethatfile` | Moves `/tmp/betty` to `/tmp/my_first_directory` |
| `8-firstdelete` | Deletes `/tmp/my_first_directory/betty` |
| `9-firstdirdeletion` | Deletes the directory `/tmp/my_first_directory` |
| `10-back` | Changes the working directory to the previous one |
| `11-lists` | Lists all files of the current, parent and `/boot` directories in long format |
| `12-file_type` | Prints the type of the file `/tmp/iamafile` |
| `13-symbolic_link` | Creates a symbolic link `__ls__` to `/bin/ls` in the current directory |
| `14-copy_html` | Copies HTML files to the parent directory if new or newer there |
| `15-lets_move` | Moves files beginning with an uppercase letter to `/tmp/u` |
| `16-clean_emacs` | Deletes files ending with `~` in the current directory |
| `17-tree` | Creates `welcome/to/school` in the current directory |
