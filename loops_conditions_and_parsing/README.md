# Shell, loops, conditions and parsing

Bash scripts practicing loops (`for`, `while`, `until`), conditions
(`if`, `elif`, `else`, `case`) and parsing (`cut`, `IFS`, `awk`).

| File | Description |
| ---- | ----------- |
| `1-for_best_school` | Displays `Best School` 10 times with a `for` loop |
| `2-while_best_school` | Displays `Best School` 10 times with a `while` loop |
| `3-until_best_school` | Displays `Best School` 10 times with an `until` loop |
| `4-if_9_say_hi` | Displays `Best School` 10 times, and `Hi` after the 9th iteration |
| `5-4_bad_luck_8_is_your_chance` | Displays `bad luck` on the 4th iteration, `good luck` on the 8th, `Best School` otherwise |
| `6-superstitious_numbers` | Displays numbers 1 to 20 with superstitious messages on 4, 9 and 17 |
| `7-clock` | Displays hours 0 to 12 and minutes 1 to 59 |
| `8-for_ls` | Lists the current directory, showing only the part of each name after the first dash |
| `9-to_file_or_not_to_file` | Gives information about the `school` file |
| `10-fizzbuzz` | Displays numbers 1 to 100 with `Fizz`, `Buzz` and `FizzBuzz` |
| `11-read_and_cut` | Displays username, user id and home directory from `/etc/passwd` |
| `12-tell_the_story_of_passwd` | Tells a story based on `/etc/passwd` using `while` and `IFS` |
| `13-lets_parse_apache_logs` | Displays visitor IP and HTTP status code from `apache-access.log` |
| `14-dig_the-data` | Groups visitors by IP and HTTP status code, ordered by occurrences |
